## 设计要点

- **L0 的定义性性质**：零跨机集合通信 ⇒ 不受 RCCL 大包吞吐未取证的影响。但（审查纠正）**这不等于风险最低**——它规避的是「跑多快」级风险，换来的是「跑不跑得动」级风险（A-1）。
- **切分方式反向决定合并方法**：IID 切分下 CAT 的适用域存疑（论文设定是不同 skill 合并），故默认加权平均。
- **三臂对照强制**（I-3）：`base` / `ad_single` / `ad_merged`——「合并是否优于单站」是 L0 的全部价值主张，无对照即不可判。
- **故障域在编排层**（审查纠正）：叶子脚本各有签名不等于系统能跑，故补 `orchestrate` 模块 + 五件必设。
- **前置拒绝替代事后检测**（I-6 改写）：本仓无 MIG 隔离，探针只能确认会死、不能防死。
